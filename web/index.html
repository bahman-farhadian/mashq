About Tartarus

Tartarus is a self-hosted, active-recall language trainer. Word lists are JSON files you own; SQLite keeps only scores and practice history.

Practice is deliberately a concentration exercise, not a typing race. Answer fields stay locked while audio is playing so you listen first, recall the material, and then type it. Audio currently works only on macOS through the local say command.

Philosophy: The Depths of Neuroplasticity

The name Tartarus is drawn from Greek mythology—the deepest abyss of the underworld, used as a dungeon of torment and a prison for the Titans. But why name a language learning application after a mythological abyss? The answer lies in neuroplasticity.

Neuroplasticity is the brain's remarkable ability to reorganize itself by forming new neural connections. However, true mastery isn't forged in comfort; it is forged through intense repetition, struggle, and deep concentration. Tartarus represents plunging vocabulary into the deepest depths of your memory. By relentlessly drilling words until they become second nature—much like enduring the deepest depths of the abyss—you exploit your brain's neuroplasticity to forge permanent, inescapable linguistic skills.

The 10-Day Gauntlet

Tartarus enforces a Dual-Track Architecture: every word list progresses through a strict 10-day descent and is simultaneously maintained through the lifetime Leitner spaced-repetition system. The backend auto-determines your session type — you simply show up and fight.

  • Day 0 — The Forging: Standard progressive learning until all 64 words reach mastery (score 9.0).
  • Days 1–2 — The Crucible: Audio-only. The word is completely hidden. You listen and type from memory.
  • Days 3–4 — The Shadows: The word appears with heavy masking. Only the first letter is revealed.
  • Days 5–6 — The Depths: Rapid fire. Definition + audio shown. No hesitation permitted.
  • Days 7–8 — The Void: Reverse translation. Only the definition. Audio plays. Type the target word.
  • Days 9–10 — Ascension: Final audio-only review. The word must live in your mind, not on screen.

Each stage requires 4 sessions (64 questions) per day. Once the daily quota is met, the list is locked until midnight — neuroplasticity requires sleep. Rage-quitting a session voids all progress for that session. Mistakes trigger an inescapable 9-repetition drill.

How practice works

Every word and sentence has a score from 0.0 (new) to 9.0 (mastered). Correct answers add 0.5. A wrong answer keeps the score but starts a nine-correct drill. Mastered material moves through ten daily Leitner boxes. See the tab for your history, or read the full scoring breakdown in the project's README.

Local-first data

The CLI and web UI load the same JSON material and update the same local progress database. Every answer updates progress immediately, and ending a session writes its summary to the database.

Samples and personal material

Bundled Tartarus samples are read-only and exist only to evaluate the learning flow. As soon as you create personal vocabulary or sentence material, samples are hidden for that user and their sample practice history is removed. Your JSON material and personal history remain.

Tracking your progress

The tab shows your session history — sessions, time spent, words practiced, and correct/incorrect/drilled counts, per day and in total. Add a language there too, and you'll also see that word list's current words: each one's score, growth gauge, and full practice history (times practiced, correct, incorrect, drilled, flagged, and mastered).

Practice Modes (historical)

  • Gauntlet: The default. Backend auto-determines the session type based on your current day and progress.

Multiple word lists per language

A single user can have as many word lists as they like. The Word list field on the Practice page is just a list name — you can use anything: german_home, german_health, english_b2. Each name gets its own JSON file and its own score history in the database, so you can practice each topic independently. If the list name doesn't auto-detect as a language for audio (e.g. german_home), fill in the optional Audio language field (e.g. german) to get the right voice.

Customizing your word lists

Use the tab to create a new list and edit its words and definitions directly — no JSON editing required. Each word can have up to two definitions (e.g. an English meaning and a German one), and German nouns written with their article (der/die/das) are color-coded by gender automatically.

Keyboard-friendly

Every page's main button doubles as the Enter key on its input fields — start a session, load a report, or create and load a word list without touching the mouse. If you press Enter while a required field is empty, focus jumps to that field instead of submitting.

This web UI

Runs entirely on 127.0.0.1:9999 — standard library Python only, no external dependencies, no data ever leaves your machine.
